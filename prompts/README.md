# 기능별 구현 프롬프트

새 세션 하나가 프롬프트 하나를 맡는다. **각 세션에 `00-공통.md`와 해당 기능 파일을 함께 준다.**

## 순서

```
00 기술 탐침 ──> 02 사연 쓰기 ──> 03 Q 피드 ──> 04 진료
  (스택이 도는가)    (제품의 축)      (별표)      (별표한 의료진)

01 온보딩 ─── 02가 끝난 뒤. 온보딩이 무엇을 약속할지가 02에서 정해진다

05 주변 ─┐
06 메뉴 ─┴─ 아무 때나. 다른 것과 얽히지 않는다
```

**00을 맨 먼저 한다.** 한국어 음성 전사가 되는지가 스택을 고른 이유(`DECISIONS.md` D-1)다.
안 뚫리면 화면 여섯을 만든 뒤가 아니라 지금 알아야 한다.

**그다음 02다.** 사연이 없으면 Q에 볼 것이 없고, Q에 답변이 없으면 별표할 의사가 없고, 별표가 없으면 진료 탭의 「새 의료진」이 비어 있다.

## 한 세션에 주는 말

```
MediVU/MediVU-app 에서 작업한다.
prompts/00-공통.md 와 prompts/02-사연쓰기.md 를 읽고 그대로 구현해라.
```

디자인 규칙(`CLAUDE.md`)은 세션에 자동으로 들어오므로 따로 주지 않는다.
`00-기술탐침.md`는 구현이 아니라 확인이다 — 「읽고 그대로 확인해라」로 준다.

## 겹치는 파일 — 순서를 지켜야 하는 이유

| 파일 | 누가 만지나 | 어떻게 푸나 |
| --- | --- | --- |
| `src/components/ui/*` | 전부 | **먼저 하는 세션이 만든다.** 뒤 세션은 있는 것을 쓰고, 모자라면 추가만 한다 |
| `src/theme/tokens.ts` | 전부 | 값을 바꾸지 않는다. 필요하면 **추가**하고 왜 필요한지 주석에 남긴다 |
| `src/components/app-tabs.tsx` | 없음 | 탭 구성은 끝났다. 만지지 않는다 |
| `src/data/rules/` | 02 · 04 | 서로 다른 파일이라 겹치지 않는다 |

## 세션이 끝나면

세 관문 모두 **0건**이어야 한다. 지금 저장소가 0건인 상태에서 시작한다.

```bash
npx tsc --noEmit
npm run lint
npm run test:run
```

그다음:

- 웹 미리보기(`npm run web`)로 눈 확인 — 모바일 375×812 기준
- `DECISIONS.md`와 어긋나게 만든 것이 있으면 그 파일에 적는다
- **커밋하고 푸시한다.** 다음 세션이 이어받을 수 있어야 한다
- 보고는 `CLAUDE.md` §13 형식으로 — 특히 `AUTO / DEV / USER`를 나눠 적는다.
  사용자 시험을 안 했으면 **「사용성 미검증」이라고 쓴다**

## 세션을 동시에 돌리지 않는다

작업 트리가 하나다. 두 세션이 같이 돌면 `src/components/ui/`와 `tokens.ts`에서 부딪힌다.
**한 번에 하나씩, 끝나면 커밋하고 다음을 연다.**

굳이 병렬로 하겠다면 `05 주변`과 `06 메뉴`만 후보다. 서로도, 다른 것과도 얽히지 않는다.
그때는 `git worktree`로 트리를 갈라야 한다.
