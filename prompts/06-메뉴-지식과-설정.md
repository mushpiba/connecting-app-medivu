# 06 · 메뉴 — 절차 지식과 설정

> `00-공통.md`를 먼저 읽는다. 다른 기능과 얽히지 않는다.

## 만드는 것

`메뉴` 탭 항목들의 실제 내용. 라우트는 `src/app/menu/`. 지금은 목록만 있고 **누르면 아무 데도 가지 않는다.**

## 여기 두는 것과 두지 않는 것

**절차 지식만 둔다.** 「이 증상은 무슨 병인가」로 넘어가는 순간 진단이 되고, 진단은 이 앱이 하지 않는 일이다.

| 둔다 | 두지 않는다 |
| --- | --- |
| 급여와 비급여의 차이 | 증상별 질환 설명 |
| 1·2·3차 의료기관과 진료의뢰서 | 「이럴 땐 무슨 과」 자가 판단표 |
| 비대면 진료를 받을 수 있는 조건 | 약 정보·복용법 |
| 진료과를 모를 때 하는 일 | |
| 본인부담상한제 · 재난적 의료비 지원 | |

**출처와 확인 시점을 각 문서에 적는다.** 제도는 바뀐다. 「2026년 9월 확인」이 문서 안에 있어야 나중에 낡은 것을 찾을 수 있다.

## 「내 정보」쪽

- **글자 크기와 화면** — OS 설정을 따르는 것이 기본이고, 앱 안에도 조절 수단을 둔다. OS 설정을 켜야만 쓸 만한 화면이면 그건 실패다
- **알림 받기** — 알림 문구에 **증상을 넣지 않는다.** 잠금화면에 뜬다. 「답변이 도착했어요」까지만
- **이 앱이 하는 일과 하지 않는 일** — 홈에 깔려 있던 고지를 여기로 옮겼다. 진단하지 않는다 · 병원을 추천하지 않는다 · 응급에는 119
- **도움말** — 모든 화면에서 같은 자리로 갈 수 있어야 한다

## 화면 규칙

- 글이 길어지는 화면이다. **한 문장 40자, 한 문장에 한 정보**를 여기서 특히 지킨다
- 전문 용어는 첫 등장에 괄호로 푼다 — `본인확인(휴대폰으로 신분을 확인하는 절차)`
- 접었다 펴는 방식을 쓰면 **열림 상태가 뒤로 가기 후에도 남게** 한다

## 완료 조건

- [ ] 목록 항목이 전부 내용이 있는 화면으로 간다
- [ ] 각 문서에 출처와 확인 시점이 있다
- [ ] 앱 안 글자 크기 조절이 실제로 동작한다
- [ ] 증상 지식이 한 줄도 들어가지 않았다
