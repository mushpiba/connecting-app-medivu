# 05 · 주변 — 의료기관 목록

> `00-공통.md`를 먼저 읽는다. 다른 기능과 얽히지 않아 순서를 바꿔도 된다.

## 만드는 것

가까운 의료기관을 **목록으로** 보여 준다. 라우트는 `src/app/nearby/`.

## 지도를 만들지 않는다

국내 1위 비대면진료 앱조차 카카오·네이버·구글 **네이티브 지도 SDK를 하나도 싣지 않았다**(APK 해체본 확인). 지도가 없어서 못 하는 일이 아니다.

- 목록으로 연다
- 위치 확인이 필요하면 **기기에 설치된 지도 앱으로 넘긴다**
- 이 결정이 뒤집히면 스택 선택까지 흔들린다. 바꾸려면 `DECISIONS.md` D-4를 먼저 고친다

## 데이터

- 공공 데이터(건강보험심사평가원 병원정보 서비스)를 쓴다. **이용 조건·인증키·갱신 주기를 먼저 확인한다** — 아직 확인되지 않았다
- 공공 데이터의 기관과 **앱에 등록돼 진료를 받을 수 있는 기관**은 다르다. 섞지 말고 구분해 표시한다
- 서버가 없으므로 `src/data/`에 모듈로 두고 화면이 직접 fetch하지 않는다

## 화면 규칙

- **위치 권한은 필요한 순간에 요청하고, 거부해도 목록을 볼 수 있어야 한다.** 지역을 직접 고르는 길을 남긴다
- 위치는 정렬에만 쓰고 저장하지 않는다. 그 사실을 권한 요청 시점에 한 줄로 말한다
- 1·2·3차 구분은 **색과 글자를 함께** 쓴다. 색만으로 구분하지 않는다
- 1·2·3차가 무엇인지는 여기서 설명하지 않는다. `메뉴` 탭에 그 항목이 있다
- 「지금 진료 중」은 사실 정보다. **추천이 아니다** — 「추천 병원」 「인기」 같은 묶음을 만들지 않는다

## 완료 조건

- [ ] 위치 권한을 거부해도 목록을 볼 수 있다
- [ ] 앱 등록 기관과 공공 데이터 기관이 구분돼 보인다
- [ ] 등급 표시가 회색조로 변환해도 구분된다
- [ ] 목록이 0건일 때 다음 행동이 있다
